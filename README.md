# عصر مکعب‌ها — Voxel Age

بازی استراتژی داستانی، دنیای باز، سبک ووکسل/پیکسلی: از **عصر حجر (صفر)** شروع می‌کنی و تا **دنیای مدرن** (تانک و بالگرد) پیشرفت می‌کنی.
۵ عصر ← ۵ فصل داستان ← هر عصر ظاهر ساختمان، سرباز و جاده عوض می‌شه. دشمن (غارتگرهای شرق) موج‌موج حمله می‌کنه.

## اجرا
```
pip install -r requirements.txt
python app.py        # http://localhost:10000
```
بدون `MONGO_URI` پیشرفت‌ها موقتی‌ان. دیپلوی Render مثل پروژه‌ی قبلی (`render.yaml` آماده‌ست؛ متغیرها: `BOT_TOKEN`, `MONGO_URI`).
با `BOT_TOKEN` ربات تلگرام و مینی‌اپ خودکار راه می‌افته؛ بدون اون هم در مرورگر با شناسه‌ی مهمان کار می‌کنه.

## ساختار (عمداً ساده)
| فایل | کار |
|---|---|
| `app.py` | کل بک‌اند: ذخیره/بارگذاری پیشرفت، رتبه‌ها، هویت تلگرام (initData)، وب‌هوک ربات |
| `web/index.html` | کل بازی (CSS + رندر three.js + منطق + رابط). داخلش با بنر `۱…۹` بخش‌بندی شده |

وقتی بزرگ شد، هر بخش `index.html` (داده‌ها، دنیا، مدل‌ها، رندر، موجودات، داستان، رابط، شبکه، حلقه) یک فایل می‌شه.

## کجا چی رو عوض کنم؟ (داخل `web/index.html`)
- **عصرها، ساختمان‌ها، سرباز‌ها (قیمت/جان/قدرت)، داستان و هدف‌ها:** بخش ۱ (`ERAS`, `BD`, `UD`, `CH`)
- **شکل زمین و جاده:** بخش ۲ (`genTerrain`) · **ظاهر ساختمان‌ها/سرباز‌ها:** بخش ۳ (`MB`, `HUMS`)
- **افکت انفجار/نور شب‌وروز:** `boom` در بخش ۴، `lighting` در بخش ۶
- **سختی دشمن و موج‌ها:** `launchWave` / `stepEnemy` در بخش ۶
- **اندازه‌ی پیکسل‌ها:** تنظیمات داخل بازی (⚙️) یا `QUAL` در بخش ۴

## کنترل
یک انگشت = جابه‌جایی · دو انگشت = زوم/چرخش · روی کارگر و بعد درخت/سنگ = جمع‌آوری · روی زمین = حرکت · روی دشمن = حمله · پایین صفحه = ساخت · روی قلعه = ارتقای عصر.
دسکتاپ: ماوس چپ انتخاب/فرمان، راست-کشیدن چرخش، چرخ ماوس زوم، WASD حرکت دوربین.

## نکته
امتیاز رتبه‌ها از کلاینت می‌آد (برای مسابقه‌ی جدی باید سمت سرور محاسبه بشه).
