# دهکدهٔ تکامل — Evolution Village 🪨→🏙️

بازی وب سه‌بعدی پیکسلی (Three.js + Flask): سوروایوال از **عصر سنگی** (آتش و چادر) شروع می‌کنی،
منابع جمع می‌کنی، جمعیت را زنده نگه می‌داری و دهکده را عصر به عصر تا **عصر مدرن** (برج برق، آسمان‌خراش، ماشین) توسعه می‌دهی.

## اجرا
```bash
pip install -r requirements.txt
python app.py        # http://localhost:10000
```
دیپلوی: `gunicorn app:app` — بدون هیچ متغیر محیطی هم کار می‌کند (ذخیره در فایل `data/*.json`).

## گیم‌پلی
- **منابع:** 🍖 غذا (سقف دارد، با انبار بالا می‌رود) · 🪵 چوب · 🪨 سنگ · 📜 علم · 🪙 طلا
- **سوروایوال:** هر شهروند غذا می‌خورد؛ اگر غذا تمام شود جمعیت کم می‌شود!
- **تکامل:** با دکمهٔ «تکامل» و پرداخت هزینه به عصر بعدی می‌روی؛ همهٔ ساختمان‌ها نونوار می‌شوند و جاده/ماشین در عصر صنعتی می‌آید.
- **ذخیره:** خودکار هر ۱۰ ثانیه (سرور + localStorage).

## ساختار فایل‌ها
| فایل | نقش |
|---|---|
| `server/__init__.py` | وب‌سرویس: `/api/join` و `/api/save` (فایل JSON) |
| `web/js/core/engine.js` | رندرر پیکسلی، دوربین، نور، روز/شب |
| `web/js/core/state.js` | منطق اقتصاد، کاتالوگ، ادوار |
| `web/js/world/terrain.js` | جزیرهٔ پیکسلی، آب، درخت |
| `web/js/world/buildings.js` | مدل ساختمان‌ها + جاده و ماشین |
| `web/js/world/people.js` | روستایی‌ها و انیمیشن راه‌رفتن |
| `web/js/world/effects.js` | آتش، دود، جشن |
| `web/js/ui/hud.js` | رابط کاربری فارسی |
| `web/js/net/sync.js` | ذخیره/بازیابی |

## توسعهٔ بعدی
- آیتم جدید → `CATALOG` در `state.js` + مدل در `buildings.js`
- عصر جدید → آرایهٔ `ERAS` + هزینه در `ERA_COST`
