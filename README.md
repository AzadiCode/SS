# Az Sefr — بقا تا تمدن (نمونهٔ اولیه)

این نسخه بر پایهٔ ساختار پروژهٔ Tribe World ساخته شده است: Flask، MongoDB اختیاری، Render، Three.js و OrbitControls حفظ شده‌اند. تجربهٔ قبلی در مسیر `/legacy` باقی مانده است.

## اجرا
```bash
pip install -r requirements.txt
python app.py
```
سپس `http://localhost:10000` را باز کن. برای ماندگاری داده‌ها بین ری‌استارت‌ها، `MONGO_URI` را تنظیم کن؛ بدون آن داده‌ها در حافظهٔ موقت نگهداری می‌شوند.

## امکانات نمونه
- محیط سه‌بعدی با ظاهر voxel / pixel-inspired و دوربین قابل چرخش و زوم
- جمع‌آوری غذا، چوب، سنگ و الیاف
- ساخت پناهگاه، مزرعه، کارگاه، کوره، پادگان، کارخانه و آزمایشگاه در عصرهای مربوط
- پژوهش و ارتقای عصر از عصر سنگ تا عصر مدرن (دروازه‌های منابع نمونه)
- API مستقل در `/api/survival/state` و `/api/survival/action`
- ذخیرهٔ دنیای نمونه در collection جداگانهٔ `survival_world`؛ داده‌های قبلی `world` دست‌نخورده‌اند

## محدودیت‌های فعلی
این یک vertical slice قابل اجرا برای اثبات ساختار و حلقهٔ بازی است، نه بازی کامل: هنوز حرکت شخصیت، مبارزه، دشمنان، چندنفرهٔ هم‌زمان، سیستم بقا با گرسنگی/سلامتی، محتوای کامل هر عصر، صدا و دارایی‌های هنری نهایی پیاده‌سازی نشده‌اند. مدل‌ها در این نسخه با هندسه‌های سادهٔ بلوکی ساخته می‌شوند و برای نسخهٔ تولیدی باید با sprite/voxel art اختصاصی جایگزین شوند.
